Mechanische Taster erzeugen beim Betätigen und Loslassen kurzzeitige Spannungsschwankungen (Prellen). Die Schaltung soll das Eingangssignal i_switch filtern und erst dann an den Ausgang o_switch weitergeben, wenn der neue Zustand über die gesamte Entprellzeit DEBOUNCE_TIME_MS stabil geblieben ist. Die Berechnung der benötigten Taktzyklen erfolgt über die Taktfrequenz CLK_FREQ_HZ. Mit jeder steigenden Taktflanke von i_clk wird geprüft, ob sich i_switch vom aktuell gespeicherten Ausgangszustand unterscheidet. Nur wenn diese Abweichung ununterbrochen für die berechnete Anzahl an Taktzyklen anliegt, übernimmt o_switch den neuen Wert. Ändert sich das Signal vorzeitig zurück, wird der interne Zähler auf 0 zurückgesetzt.


Hinweise
  • Verwenden Sie die Bibliotheken ieee.std_logic_1164.all und ieee.numeric_std.all.
  • Nutzen Sie die folgende VHDL-Entity mit den gegebenen generics, welche eine spätere Anpassung dieser Parameter vor der Synthese in Vivado erlauben, als Startpunkt: 
          library ieee;
      use ieee.std_logic_1164.all;
      use ieee.numeric_std.all;

      entity debounce_switch is
          generic (
              CLK_FREQ_HZ      : integer := 24_576_000;
              DEBOUNCE_TIME_MS : integer := 10
          );
          port (
              i_clk    : in  std_logic;
              i_switch : in  std_logic;
              o_switch : out std_logic
          );
      end entity debounce_switch;
