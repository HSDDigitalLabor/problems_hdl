{% include "file.html" %} implementieren Sie eine Steuerung für einen automatisierten Hörtest in VHDL in der Entity hearing_test_controller. Die Schaltung verarbeitet die Impulse einer Taster-Auswertung (i_pulse_short für kurze Tastendrücke und i_pulse_long für lange Tastendrücke) und besitzt ein Taktsignal i_clk sowie ein asynchrones, low-aktives Rücksetzsignal i_reset_n. Über den 4-Bit-Ausgang o_fcw_addr wird ein Block-RAM (BRAM) adressiert, in dem eine Look-Up-Table (LUT) mit NUM_FREQUENCIES verschiedenen Frequency Control Words (FCW) für einen DDS-Signalgenerator (Direct Digital Synthesis) abgelegt ist. Der 16-Bit-Ausgang o_volume gibt ein vorzeichenloses (unsigned) Lautstärke-Steuerwort an einen nachgeschalteten Multiplizierer aus, der das Ausgangssignal des DDS skaliert. Der Ausgang o_is_running steuert eine Status-LED (z. B. über ein VIO-Core) an und signalisiert, ob die Lautstärke aktuell automatisch erhöht wird (Rampe aktiv).

Funktionsweise bei steigender Taktflanke von i_clk:

  • Frequenzwechsel & Reset (i_pulse_long = '1', höchste Priorität): Die Lautstärkerampe wird gestoppt (o_is_running auf '0'), die Lautstärke o_volume sowie der interne Taktzähler werden auf 0 zurückgesetzt und die BRAM-Adresse o_fcw_addr wird um 1 erhöht. Nach Erreichen der höchsten Adresse (NUM_FREQUENCIES - 1) springt die Adresse wieder auf 0 zurück.
  • Start / Stopp toggeln (i_pulse_short = '1'): Schaltet den Status der Lautstärkerampe um (Start bzw. Pause) und setzt den internen Taktzähler für die Stufendauer auf 0 zurück. Der aktuelle Lautstärkewert bleibt beim Pausieren erhalten.
  • Automatisches Hochrampen (wenn Rampe aktiv): Innerhalb der Zeit RAMP_TIME_S wird die Lautstärke gleichmäßig in 65536 Schritten erhöht. Dazu wird jeweils nach TICKS_PER_STEP = (CLK_FREQ_HZ * RAMP_TIME_S) / 65536 Taktzyklen (Zähler von 0 bis TICKS_PER_STEP - 1) der Wert von o_volume um 1 inkrementiert. Erreicht o_volume das Maximum 0xFFFF, stoppt die Rampe beim nächsten Schritt automatisch (o_is_running wird '0') und der Lautstärkewert bleibt bei 0xFFFF stehen.

Hinweise
  • Verwenden Sie die Bibliotheken ieee.std_logic_1164.all und ieee.numeric_std.all.
  • Nutzen Sie die folgende VHDL-Entity mit den gegebenen generics, welche eine spätere Anpassung dieser Parameter vor der Synthese in Vivado erlauben, als Startpunkt: 
          library ieee;
      use ieee.std_logic_1164.all;
      use ieee.numeric_std.all;

      entity hearing_test_controller is
          generic (
              CLK_FREQ_HZ     : integer := 24_576_000;
              RAMP_TIME_S     : integer := 10;
              NUM_FREQUENCIES : integer := 8
          );
          port (
              i_clk         : in  std_logic;
              i_reset_n     : in  std_logic;
              i_pulse_short : in  std_logic;
              i_pulse_long  : in  std_logic;
              
              o_fcw_addr    : out std_logic_vector(3 downto 0); -- Geht direkt an BRAM addra
              o_volume      : out std_logic_vector(15 downto 0); -- Geht an Multiplier IP
              o_is_running  : out std_logic                      -- Status-LED
          );
      end entity hearing_test_controller;
  • Achten Sie darauf, dass das Signal i_reset_n asynchron ausgewertet wird (d. h. bei i_reset_n = '0' werden alle internen Register und Zähler sofort auf 0 gesetzt).
  • Berechnen Sie die Anzahl der Takte pro Lautstärkestufe über eine Konstante: constant TICKS_PER_STEP : integer := (CLK_FREQ_HZ * RAMP_TIME_S) / 65536; (für die Standardwerte ergibt dies exakt 3750 Taktzyklen pro Stufe).
  • Verwenden Sie intern den Datentyp unsigned für die BRAM-Adresse und die Lautstärke und konvertieren Sie diese bei der Zuweisung an die Ausgangsports mittels std_logic_vector(...).
  • Verwenden Sie die Funktion rising_edge(i_clk) zur Erkennung der steigenden Taktflanke.

Betrachten Sie neben den möglichen Warnungen und Fehlermeldungen in der Konsole auch die folgenden Szenarien im Waveform-Viewer:

  • Testen des asynchronen Resets:
    i_reset_n <= '0'; -- o_fcw_addr = 0x0, o_volume = 0x0000, o_is_running = '0'
  • Testen von Start/Stopp und Hochrampen (i_pulse_short):
    i_pulse_short <= '1'; -- für 1 Taktzyklus
    Nach der steigenden Taktflanke gilt o_is_running = '1'. Alle 3750 Taktzyklen erhöht sich o_volume um 1. Ein erneuter Impuls an i_pulse_short pausiert den Vorgang (o_is_running = '0'), wobei o_volume seinen aktuellen Wert behält.
  • Testen des Frequenzwechsels (i_pulse_long):
    i_pulse_long <= '1'; -- für 1 Taktzyklus
    Nach der steigenden Taktflanke wird o_fcw_addr um 1 inkrementiert (Wrap-Around von 7 auf 0 bei NUM_FREQUENCIES = 8), während o_volume auf 0x0000 und o_is_running auf '0' zurückgesetzt werden.
