{% include "file.html" %} implementieren Sie eine Schaltung zur Auswertung der Betätigungsdauer eines Tasters in VHDL in der Entity button_duration_detector. Die Schaltung wertet ein bereits entprelltes Tastersignal i_switch aus und unterscheidet zwischen einem kurzen (< 1 s) und einem langen (>= 1 s) Tastendruck. Zusätzlich besitzt die Schaltung ein Taktsignal i_clk sowie ein asynchrones, low-aktives Rücksetzsignal i_reset_n. Wird der Taster mindestens eine Sekunde lang gehalten (entspricht CLK_FREQ_HZ Taktzyklen), soll sofort für genau einen Taktzyklus ein Impuls an o_pulse_long ausgegeben werden. Wird der Taster hingegen vor Ablauf einer Sekunde wieder losgelassen (fallende Flanke an i_switch), wird für genau einen Taktzyklus ein Impuls an o_pulse_short erzeugt. Nach einem bereits ausgelösten langen Tastendruck darf beim anschließenden Loslassen kein zusätzlicher kurzer Impuls mehr entstehen.


Hinweise
  • Verwenden Sie die Bibliotheken ieee.std_logic_1164.all und ieee.numeric_std.all.
  • Nutzen Sie die folgende VHDL-Entity mit dem gegebenen generic, welches eine spätere Anpassung dieses Parameters vor der Synthese in Vivado erlaubt, als Startpunkt: 
          library ieee;
      use ieee.std_logic_1164.all;
      use ieee.numeric_std.all;

      entity button_duration_detector is
          generic (
              CLK_FREQ_HZ : integer := 24_576_000
          );
          port (
              i_clk         : in  std_logic;
              i_reset_n     : in  std_logic;
              i_switch      : in  std_logic; -- Entprelltes Tastersignal
              o_pulse_short : out std_logic; -- 1 Takt Impuls: Druck < 1 s
              o_pulse_long  : out std_logic  -- 1 Takt Impuls: Druck >= 1 s
          );
      end entity button_duration_detector;
  • Achten Sie darauf, dass das Signal i_reset_n asynchron ausgewertet wird (d. h. bei i_reset_n = '0' werden alle Ausgänge und internen Signale sofort auf 0 bzw. '0' gesetzt).
  • Definieren Sie eine Konstante für die Anzahl der Takte pro Sekunde: constant ONE_SEC_TICKS : integer := CLK_FREQ_HZ;.
  • Speichern Sie den vorherigen Zustand von i_switch in einem Hilfssignal (z. B. btn_prev), um das Loslassen des Tasters (btn_prev = '1' and i_switch = '0') zuverlässig zu erkennen.
  • Merken Sie sich über ein Statussignal (z. B. long_triggered), ob während des aktuellen Tastendrucks bereits o_pulse_long ausgelöst wurde, damit beim Loslassen nicht fälschlicherweise o_pulse_short aktiviert wird.
  • Verwenden Sie die Funktion rising_edge(i_clk) zur Erkennung der steigenden Taktflanke.

Betrachten Sie neben den möglichen Warnungen und Fehlermeldungen in der Konsole auch die folgenden Szenarien im Waveform-Viewer:

  • Testen des asynchronen Resets:
    i_reset_n <= '0'; -- o_pulse_short und o_pulse_long müssen sofort '0' annehmen
  • Testen eines kurzen Tastendrucks (< 1 s):
    i_switch <= '1'; -- für weniger als 24.576.000 Takte halten, dann i_switch <= '0';
    Direkt mit der ersten steigenden Taktflanke nach dem Loslassen muss gelten:
    o_pulse_short = '1' (für exakt einen Taktzyklus) und o_pulse_long = '0'.
  • Testen eines langen Tastendrucks (>= 1 s):
    i_switch <= '1'; -- für mindestens 24.576.000 Takte halten
    Exakt beim Erreichen von 24.576.000 Takten muss für einen Taktzyklus o_pulse_long = '1' gelten. Beim späteren Loslassen (i_switch <= '0') muss o_pulse_short = '0' bleiben.
