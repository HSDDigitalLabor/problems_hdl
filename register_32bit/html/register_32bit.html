Das Register besitzt einen Dateneingang data_in (32 Bit), einen Datenausgang data_out (32 Bit), ein Taktsignal clk sowie ein asynchrones Rücksetzsignal reset. Bei aktivem Reset ('0' low-active) soll der Ausgang sofort auf 0 gesetzt werden. Mit jeder steigenden Taktflanke von clk wird der Wert an data_in übernommen und an data_out ausgegeben.


Hinweise
  • Verwenden Sie die Bibliothek ieee.std_logic_1164.all für die Datentypen std_logic und std_logic_vector.
  • Achten Sie darauf, dass das Signal reset asynchron ausgewertet wird (d. h. vor der Taktflankenprüfung im process).
  • Verwenden Sie die Funktion rising_edge(clk) zur Erkennung der steigenden Taktflanke.
  • Um alle 32 Bits gleichzeitig auf '0' zu setzen, empfiehlt sich das Aggregat: data_out <= (others => '0');
